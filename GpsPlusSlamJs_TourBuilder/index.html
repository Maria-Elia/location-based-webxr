TourBuilder — component gallery

Each component is an isolated, individually runnable demo. Add a folder under components/ and an entry in vite.config.ts, then link it here.

  • Component 1 — Clickable billboard Yaw-to-face sprite that plays an audio clip and shows an in-world transport panel.
  • Component 2 — In-world text Billboarded, paginated transcript panel rendered via HTML-in-3D with a CanvasTexture fallback; XR-safe.
  • Component 3 — Tour data model + store The shared tour.json schema, validator, Redux slices, selectors and two store factories — an interactive state control panel.
  • Component 4 — Proximity & zone state machine A real recorded walk replayed top-down; each waypoint crosses IDLE → PREFETCHING → ACTIVE with hysteresis. No phone.
  • Component 5 — Tour packaging & QR Bundles a tour + its assets into an uncompressed tour.zip (range-readable, no DEFLATE) and turns the hosted URL into a scannable viewing link.
  • Component 6 — Cloud-storage tour source Turns a shared ?tour= link into a running tour: byte-range reads over the network, an on-demand asset provider, and a background warm that switches to a local copy — with a full-download fallback when a host refuses ranges.
  • Component 7 — 2D map overview A toggleable, real-time 2D Leaflet map (no Three.js) showing the visitor's position and the tour's waypoints, driven by the real store + proximity driver.
  • Component 8 — AR viewing scene The Three.js side of viewing mode: anchored knights that load invisibly at 25 m and appear at 10 m, tap-to-play stories with a floating transcript, and a recycled trail of breadcrumb orbs — a real recorded walk, replayed on the desktop.
  • Component 9 — Onboarding gate + audio unlock A mandatory camera/GPS permissions checklist — Start only enables once the browser reports both granted — whose click is also the gesture that unlocks the Web Audio API.
  • Component 10 — Authoring tools Drop waypoints at the live GPS position (or a replayed Task 1 walk), attach model/sprite/audio files, record the breadcrumb trail, and export a real tour.zip via component 5.
  • Component 11 — Desktop preview Walk a real tour on a desktop with no phone, no GPS and no WebXR: a pinned frame and a first-person camera stand in for the AR session, and component 8's scene runs inside unchanged.
